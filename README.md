# PÉONIA Studio — лендинг

Односторінковий сайт студії з продажу піонів для букетів (Німеччина).
Статичні файли, нуль залежностей і нуль кроків збірки: відкривається подвійним кліком по
`index.html` і заливається на будь-який хостинг простим копіюванням.

Візуальні рішення — у [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md). Правити стилі варто, тримаючи його
поруч: там записані токени, типографічні правила й вісім патернів блоків.

```
index.html                 вся розмітка, німецький текст інлайн
assets/css/styles.css      токени + усі секції
assets/js/i18n.js          українські переклади
assets/js/main.js          мова, «завіса», рейки, лайтбокс, форма
assets/img/*.svg           25 тимчасових ілюстрацій
favicon.svg
DESIGN-SYSTEM.md
```

## Дві мови

Німецька лежить **інлайн у HTML** — сторінка індексується німецькою й повністю працює з
вимкненим JS. `assets/js/i18n.js` містить **лише українські** рядки; при поверненні на DE
текст відновлюється з кеша, знятого з DOM при завантаженні.

- Правите німецький текст — правите `index.html`.
- Правите український — правите `i18n.js`, ключ у ключ із `data-i18n`.
- **Одне правило:** `data-i18n` ставиться на вузол, усередині якого немає вкладених тегів —
  переклад переписує весь вміст. Якщо частину рядка треба виділити, ключі йдуть на дочірні
  елементи, а не на батька. Порушення `main.js` виявляє й пише попередження в консоль.
- Прямі посилання: `?lang=uk` і `?lang=de`. Вибір запам'ятовується в `localStorage`.
- Перемикає мову тумблер із глобусом у хедері: показує поточну мову, клік міняє її на другу.
  Разом із текстом перемикаються `<title>`, опис сторінки й атрибут `lang`.

**Мова за замовчуванням — українська.** Німецька лишається в HTML як вихідний текст, тож
пошуковики й браузер із вимкненим JS бачать саме її. Для німецького ринку типовою логічніше
зробити німецьку: у `assets/js/main.js` у рядку
`(localStorage.getItem("peonia-lang") || "uk")` замініть `"uk"` на `"de"` — і там же
`var wanted = "uk"` на `"de"`.

**Скрипт-акценти.** Pinyon Script не має кирилиці, тому в українській версії акцентні слова
автоматично переходять на курсив Jost плюс колір (правило `html[lang="uk"] .sw` у CSS).
Якщо потрібен однаковий рукописний вигляд в обох мовах — потрібен шрифт із кирилицею.

### Як додати свою квітку

Вирізи зроблено моделлю **rembg** (u2net та isnet-general-use) з alpha-matting на краях.
Для встановлення знадобилися пакети `Pillow`, `numpy`, `scipy`, `rembg` (у користувацький
`~/Library/Python/3.9`) і модель ~176 МБ у `~/.u2net/`.

```bash
python3 -m pip install --user "rembg[cpu]"
```

```python
from PIL import Image
from rembg import remove, new_session
sess = new_session("u2net")          # або "isnet-general-use" для блідих квітів
im = Image.open("photo.jpg").convert("RGB")
im.thumbnail((1250, 1250), Image.LANCZOS)
out = remove(im, session=sess, alpha_matting=True,
             alpha_matting_foreground_threshold=250,
             alpha_matting_background_threshold=15,
             alpha_matting_erode_size=6)
out.crop(out.getbbox()).save("bloom-new.webp", "WEBP",
                             quality=88, method=6, alpha_quality=94)
```

Що важливо при доборі знімка:

- Квітка має вміщатися в кадр **цілком**. Зрізане краєм суцвіття виглядає як брак.
- Хочете листя — беріть кадр, де рослина зі стеблом знята **на рівній стіні**: тоді модель
  тримає весь кущик одним об'єктом. На знімках із саду вона лишає саме суцвіття, бо листя
  позаду для неї — тло.
- Ніколи не обмежуйте виріз геометричною маскою: коло чи еліпс одразу читаються як рамка.

## Форма

**Форма нічого не надсилає.** Перевірка полів клієнтська, після успіху показується
повідомлення, але запит нікуди не йде — бекенду немає.

Щоб увімкнути, наприклад через Formspree:

```html
<form class="form" id="form" action="https://formspree.io/f/ВАШ_ID" method="POST">
```

і в `assets/js/main.js` у обробнику `submit` прибрати `e.preventDefault()` та виклик
`form.reset()` — далі відправку робить браузер. Для Netlify Forms достатньо додати
`netlify` і `name="contact"` на тег `<form>`.

Поки форма не підключена, робочим каналом лишається пряме посилання `mailto:` поряд із нею.

## Вступний екран «губка»

При першому відкритті сторінка закрита зеленим текстурним шаром — його треба «витерти»
мишкою або пальцем. Коли очищено **62%**, залишок зникає сам.

Що варто знати:

- Показується **при кожному відкритті та оновленні** сторінки.
- Під `prefers-reduced-motion` шар не з'являється взагалі.
- Є кнопка «Пропустити», а також Esc і Enter. Без цього люди, які користуються лише
  клавіатурою, не змогли б пройти далі.
- Через 25 секунд шар зникає сам — щоб ніхто не лишився замкненим.
- Поріг, радіус губки й зернистість краю задані в `assets/js/main.js`, блок 2:
  `0.62` (поріг) і `BR` (радіус губки).

## Доступність

Skip-link, семантичні секції з `aria-labelledby`, видимий фокус, лайтбокс із фокус-пасткою й
Esc, контраст тексту перевірений числами (≥4.5:1). Уся анімація, включно зі стартовою
«завісою», вимикається під `prefers-reduced-motion: reduce`.

Кораловий `#FF9EA9` дає на кремовому лише 1.9:1 — як текст він **не придатний**. Для
акцентних слів на світлому тлі використовуйте `--coral-ink`, для дрібного кегля
`--coral-ink-sm`. Деталі — §3 дизайн-системи.
